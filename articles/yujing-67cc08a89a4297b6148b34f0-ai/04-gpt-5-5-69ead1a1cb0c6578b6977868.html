01

两个版本，一个基调：新一类智能，为实际工作和 Agent 设计

OpenAI 官方原话是 a new class of intelligence for real work，一种为实际工作设计的新类智能。

翻译成人话：以前的 GPT 更像个聊天对象，这一代明确往干活方向拉。给它一个多步乱摊子，它会自己拆、自己用工具、自己检查、一路推到完成。GPT-5.5 比 GPT-5.4 更擅长跨上下文推理、长时间保持在目标上、在模糊处作判断。

它做得最好的四件事：

•写代码和调代码

•在线查资料做研究

•分析数据、做电子表格和文档

•操作电脑上的软件，在工具之间跳来跳去把活干完

两个版本的分工很清楚：

•GPT-5.5（在 ChatGPT 里叫 GPT-5.5 Thinking）：Plus 及以上用户日常用，更快更聪明更省 token

•GPT-5.5 Pro：Pro、Business、Enterprise 才有，面对更难的问题，追求高准确度的工作

一个之前少见的指标：GPT-5.5 每个 token 的响应时间和 GPT-5.4 完全一样。模型更强一般意味着更慢，这次没慢。OpenAI 在推理基建上动了不少心思，后面会讲。

02

Agent 编程：能看懂系统在哪里坏了

OpenAI 把 GPT-5.5 定位成“最强 Agent 编程模型”，重点不是单轮写代码，而是能跟着一个真实工程问题走很长的路：

•Terminal-Bench 2.0（82.7% SOTA）测复杂命令行工作流，要模型自己规划、反复迭代、调度工具

•SWE-Bench Pro（58.6%）测真实 GitHub issue 的端到端修复（这一项 Claude Opus 4.7 依然领先，64.3%）

•Expert-SWE（73.1%）是 OpenAI 内部评测，人类专家中位完成时间 20 小时的长周期任务

三个评测 GPT-5.5 都比 GPT-5.4 分数更高，且用更少的 token 完成。

官方主 demo 是 Artemis II 月球任务的 3D 可视化：用单张参考图 + 一句话提示，GPT-5.5 在 Vite + WebGL 里写出一个交互式 3D 轨道模拟器，用的是 NASA/JPL Horizons 的真实天体矢量数据（猎户座飞船、月球、太阳），包含真实轨道力学。这个案例能直观看出模型的“视觉理解 + 自主实现 + 自测”三件事怎么串起来。

03

Codex 升级：从会写代码扩到会跨应用干活

同一天 OpenAI Developers 官推宣布 Codex 接上 GPT-5.5，升了三个方向的自动化能力。

浏览器级

以前 Codex 写代码就停在代码里。现在 Codex 能开浏览器，和 Web App 互动，执行测试流程、点页面、截屏、根据看到的结果迭代，一直跑到任务完成。从写测试用例变成自己跑测试用例再根据结果改代码。

Office 和 Google Drive 级

能生成更高质量的电子表格、幻灯片、文档。应用里新加了文件查看器，审阅和修改迭代更快。以前你让 AI 写个 PPT 得自己去 PPT 里粘贴，现在它能在 Office 或 Drive 里直接出货。

桌面级

从看屏幕上显示什么，到点击、输入、导航、在不同工具之间转移上下文。给一个多工具流程（比如先看 Notion 需求，再到 Figma 看设计，再到 VS Code 改代码，再到 iTerm 跑测试），Codex 能一路贯穿。

Codex 还给 GPT-5.5 开了个专属的 Fast 模式：token 生成速度快 1.5 倍，费用 2.5 倍。配给你要立即看到结果的交互场景。

Codex 的上下文窗口给到 400K，API 给到 1M。

04

工程自指：OpenAI 用 GPT-5.5 优化 GPT-5.5 的基建

要让 GPT-5.5 跑得和 GPT-5.4 一样快，OpenAI 做了件不太寻常的事：让 GPT-5.5 自己去优化自己的推理基建。

具体的改进举了一个：Codex 分析了数周的生产流量模式，写出自定义的负载均衡和分区启发式算法，使 token 生成速度提升超过 20%。

打个比方理解一下。原本 OpenAI 处理请求的方式，像快递公司把每单包裹都切成相同大小再寄走，保证大单小单能挤同一辆车。但真实流量从来不均匀，有时大单扎堆、有时小单密集，固定切法会浪费。Codex 看了几周真实的流量曲线，自己写出了一套动态切法，取代了原来的固定切法。

这件事比任何基准分都值得记住：不是 demo，不是论文里的假设，是一张跑在 OpenAI 生产 GPU 上、让 token 吐得快 20% 的算法，作者栏写着 Codex。

不止这个。OpenAI 一个内部版本的 GPT-5.5（带定制 harness）还帮助发现了关于 Ramsey 数的新数学证明，结果已经用 Lean 形式化验证。Ramsey 数是组合数学里的核心对象之一，问一个网络要多大才能保证某种秩序出现。这块的新结果很少且技术门槛高。不是代码、不是解释，是一个真的有用的数学论证。

OpenAI 官方公布的内部使用数据：

•85% 的员工每周使用 Codex，覆盖软件工程、财务、公关、市场、数据科学、产品管理各部门

•Comms 团队用 Codex 分析六个月演讲请求数据，搭了评分和风险框架，训了自动 Slack Agent，低风险请求自动处理，高风险才路由到人

•Finance 团队用 Codex 审了 24,771 份 K-1 税表（71,637 页），工作流屏蔽个人信息，比去年同期提前两周完成

•Go-to-Market 团队某员工把每周业务报告的生成自动化了，一周省 5 到 10 小时

05

研究与知识工作：从答问到研究伙伴

研究工作的循环是：探索想法、收集证据、测假设、解释结果、决定下一步试什么。GPT-5.5 的提升在于能跨这整个循环持续推进，而不是每步都要重新启动。

这部分是这次发布里最“非编程”的一段，也是最值得单独看的部分。

Jackson Laboratory 免疫学教授 Derya Unutmaz 用 GPT-5.5 Pro 分析了一个包含 62 个样本、将近 28,000 个基因的表达数据集，输出一份详细的研究报告。他说这份工作如果由他的团队自己做，得花几个月。

Adam Mickiewicz 大学数学助理教授 Bartosz Naskręcki 用 Codex 里的 GPT-5.5，从一条提示词开始 11 分钟做出一个代数几何 app：可视化两个二次曲面的交线，再把交线转成 Weierstrass 模型。

•GPT-5.5 和 Claude Opus 4.7 输入价同为 $5，输出价 $30 vs $25，GPT-5.5 稍贵一点

•GPT-5.4 上下文是 2M，其他三个都是 1M，长上下文场景 GPT-5.4 还有位置

•Gemini 3.1 Pro 是价格杀手：AA 智能榜上和 Claude Opus 4.7 并列 57 分，综合价只要 GPT-5.5 的 40%

•Batch / Flex 模式：标准价一半；Priority 模式：标准价 2.5 倍

10

这次发布里有几件比跑分更有意思的事

一是 OpenAI 明说“GPT-5.5 帮我们改进了服务 GPT-5.5 的基础设施”。 过去模型在 GPU 上按固定 chunk 数切分请求做负载均衡，这不是最优方案。Codex 分析了几周生产流量模式，自己写出定制的负载均衡和分区启发式算法，token 生成速度提了 20% 以上。这是第一次 OpenAI 在官方发布里，把“模型参与底层推理栈优化”作为一个独立案例讲出来。

二是 GPT-5.5 的生物/化学和网络安全能力同时被归为 Preparedness Framework 里的 High 级别。 之前 GPT-5.2 只把 cyber 标成 High，这次生物一起升级。配套做法是一个 Trusted Access for Cyber 项目：普通 API 走严格分类器（会比之前更容易拒答和被标记），安全防御方走认证后的宽松通道；关键基础设施防御方（比如电网、供水、税务）可以单独申请一个 GPT-5.4-Cyber 模型，OpenAI 还在和政府合作探索这块。这是“强模型分级放行”范式的第二次落地，后续前沿模型发布的新模板。

三是 AA 综合智能榜上 GPT-5.5 领先 Claude Opus 4.7 三分。 这三分的来源不是单项碾压，而是分布性胜出：Agent 编程、知识工作、物理推理、指令遵循、准确率几个维度都压一点。但不幻觉率、SWE-Bench Pro、MCP Atlas、FinanceAgent 这几项 Claude 还守着。这不是“Claude 完蛋了”的局面，更像“OpenAI 用跨维度堆积领先分数，Claude 在高信任任务上还有位置”。

四是 Gemini 3.1 Pro 此次存在感比预期强。 智能指数上和 Claude Opus 4.7 并列 57 分，价格只有 GPT-5.5 的四分之一左右。如果 OpenAI 和 Anthropic 是在打旗舰战，Gemini 就是在价格/智能曲线上做功。

11

彩蛋：视频输入

GPT-5.5 将支持视频输入，很多用户前不得不总切回 Gemini 的原因，现在 ChatGPT 里补齐了。

现在已经有用户看到 ChatGPT 多了个 video tab。按特定按钮就能上传视频，支持 1M 上下文。

该功能随 GPT-5.5 将很快向所有人开放。

Gemini 3 对多模态视频理解一直领先，OpenAI 在这一代补上。对日常场景（做视频教程提问、会议记录回溯、产品演示视频总结）这是补齐核心能力。官方页面里没直接大篇幅讲视频输入，但几个独立来源都证实了这件事。
